# Portfolio Mike Kabamba
Version web inspirée du portfolio Canva.

## GitHub Pages
1. Créer le dépôt `bigmikekabamba-spec.github.io`.
2. Mettre `index.html`, `style.css`, `script.js` et `images/` à la racine.
3. Settings > Pages > Deploy from a branch > `main` > `/ (root)`.
4. Adresse : https://bigmikekabamba-spec.github.io/

## À modifier avant publication
- Dans `index.html`, remplacer l'email et le numéro WhatsApp.
- Ajouter `CV_Mike_Kabamba.pdf` à la racine.
- Remplacer `images/profile.jpg` par ta photo originale si tu veux une meilleure qualité.
- Ajouter le vrai lien LinkedIn.
